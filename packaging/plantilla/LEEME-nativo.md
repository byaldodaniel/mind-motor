# Mind 1.0.5

Ejecuta `Sistema/mind.cmd preparar` en Windows o `./Sistema/mind preparar`
en macOS y Linux para conectar los clientes detectados al Motor Rust por HTTP
local. Abre una conversación nueva en el cliente. `Sistema/mind estado` muestra
el estado de Mind y `Sistema/mind ayuda` lista las órdenes de consola.

Usa el iniciador «Autorizar Mind» para revisar solicitudes pendientes. Los
agentes reciben 13 herramientas y operan sobre su carpeta abierta o las
ubicaciones que hayas autorizado.

La Base se conserva en `Sistema/Base`. Guarda la copia anterior hasta
comprobar tus conversaciones y carpetas con la versión nueva.
