# Mind 1.0 — Motor

Proyecto nuevo, construido desde cero a partir de `docs/Concepto_Mind.pdf`.
No contiene implementaciones, pruebas ni configuraciones del Motor anterior.

## Entorno

- `Mind - Desarrollo/Motor/`: este repositorio; construcción y pruebas del Motor.
- `Mind - Desarrollo/Base/`: Base local de pruebas, independiente y fuera de Git.
- `My Mind/`: reservado para la primera versión estable, con su propia Base.

El Motor proporciona capacidades a los agentes. La Base conserva los registros
necesarios para encontrar, relacionar y dar continuidad a la información.
Los archivos originales permanecen en sus ubicaciones autorizadas.

## Estado inicial

Solo se ha preparado el entorno y la referencia conceptual. No se ha elegido
lenguaje, instalado dependencias ni implementado ninguna de las cinco funciones.
No existe todavía una aplicación que ejecutar.

## Colaboración

La rama principal es `main`. Cada incremento se trabaja en una rama y se presenta
mediante un pull request, con alcance, validación y limitaciones explícitas.
No incorporar datos personales, credenciales ni contenido de las Bases.
